## Découverte

Toutes les pages que vous consultez sur le Web sont construites à partir d'un même langage informatique :
le **HTML** _(HyperText Markup Language)_.

Ce langage, créé spécialement pour le web, permet de donner des instructions au navigateur afin de **définir** et **structurer** le contenu d'une page.
C'est grâce à lui que vous pouvez voir du texte, des images, des liens et bien d'autres éléments sur un site web.

### Le code source d'une page web

Un **code source** est un texte qui contient des instructions destinées à l'ordinateur afin de lui expliquer quoi faire.
Pour une page web, ce texte est écrit en langage HTML. Ce langage est interprété par le **navigateur web** (_Firefox_, _Chrome_, _Edge_...) qui le transforme en un contenu lisible pour les humains.
Mais à quoi ressemble le code HTML ?

<Aside type="note" title="Explications">

Dans le code source, certains éléments entourés de chevrons (`<` et `>`) comme `<h1>`, `<p>` ou `<strong>` ne s'affichent pas sur la page.

Ces éléments s'appellent des **balises** et constituent la base du langage HTML.
Elles ne sont pas visibles par l'utilisateur, mais permettent de structurer et de hiérarchiser le contenu.

Autrement dit, vous « balisez » le contenu afin d'indiquer de façon explicite au navigateur ce qui est un titre, ce qui est un paragraphe, ce qui est un texte important, etc.

</Aside>

### Les balises HTML

Les balises HTML servent à structurer le contenu d'une page web.
Chacune a un rôle précis, comme définir un titre, créer un paragraphe ou mettre du texte en valeur.
Découvrons les plus courantes avant de construire votre première page.

#### Structurer le contenu

Tout comme dans un traitement de texte, une page web est structurée avec des titres, des sous-titres et des paragraphes.
En HTML, on utilise des balises pour encadrer le texte et indiquer son rôle.

Une balise fonctionne presque toujours par paire : elle **encadre** le contenu pour indiquer où commence et se termine un **élément** (un titre, un paragraphe, etc.).

{/* prettier-ignore */}
```html annotations="side"
<!-- Cas Général -->
<balise><!-- [!annotate] Balise **ouvrante** : marque le début de l'élément. -->
  Contenu de la balise
</balise><!-- [!annotate] Balise **fermante** : marque la fin de l'élément (attention à la barre oblique `/`) -->

<!-- Exemple avec un titre -->
<h1>Bienvenue</h1><!-- [!annotate] La paire de balises `<h1> </h1>` encadrant le texte « Bienvenue » indique un élément titre. -->

<!-- Exemple avec un paragraphe -->
<p>
  Contenu de mon paragraphe.<!-- [!annotate] Les espaces et les sauts de ligne servent à rendre le code lisible pour vous ; le navigateur les ignore. Ici, la paire de balises `<p> </p>` indique un élément paragraphe. -->
</p>
```

<Checklist>

- Je sais que le HTML est le langage qui structure les pages web et que le navigateur le transforme en page lisible
- Je sais repérer les balises dans un code source : elles sont entre chevrons et ne s'affichent pas sur la page
- Je sais faire la distinction entre une balise ouvrante `<p>` et une balise fermante `</p>`
- J'ai compris que chaque balise a un rôle précis (`<h1>` pour un titre, `<p>` pour un paragraphe)
- J'ai compris que le navigateur ignore les espaces et les sauts de ligne de mon code

</Checklist>

### Structurer du texte

Une page web, comme l'énoncé de ces travaux pratiques, est découpée en parties avec des titres, des sous-titres et des paragraphes.
En HTML, chacun de ces éléments est défini par sa propre balise.

<Aside type="note" title="Les balises pour structurer le texte">

- Les balises de `<h1>` à `<h6>` définissent les niveaux de titres.<br/>`<h1>` est le titre principal (le plus gros), `<h2>` est un sous-titre, etc.
- La balise `<p>` définit un paragraphe de texte.

</Aside>

#### Mise en pratique

<Steps>

1. Remplacez le texte encadré par la paire de balises `<h1> </h1>` par votre prénom.
2. Remplacez le texte du premier sous-titre `<h2>` par le texte "Qui suis-je ?"
3. Remplacez le texte du premier paragraphe `<p>` par la phrase de votre choix.
4. Remplacez le texte du deuxième sous-titre `<h2>` par le texte "Mes passions"
5. Créez un nouveau sous-titre de niveau 3 en utilisant les balises `<h3>` et `</h3>`.<br/>Écrivez le texte de votre choix à l'intérieur.
6. Créez un nouveau paragraphe en utilisant les balises `<p>` et `</p>`.<br/>Écrivez le texte de votre choix à l'intérieur.
7. Observez comment la taille du texte change selon la balise utilisée (`h1`, `h2`, `h3` ou `p`).

</Steps>

### Mettre en valeur du texte

À l'intérieur d'un paragraphe, vous pouvez avoir besoin de faire ressortir certains mots importants ou d'insérer un saut de ligne.
En HTML, on utilise des balises spécifiques qui s'insèrent directement au milieu du texte.

<Aside type="note" title="Les balises pour mettre en valeur du texte">

- La balise `<strong>` indique une forte importance<br/>(le navigateur l'affiche généralement en **gras**).
- La balise `<em>` indique une mise en évidence<br/>(le navigateur l'affiche généralement en _italique_).
- La balise `<br>` permet d'insérer un saut de ligne simple.<br/>C'est une balise **orpheline**, elle n'a pas besoin de balise fermante.

</Aside>

#### Mise en pratique

Dans l'éditeur ci-dessous, le code d'un petit paragraphe vous est proposé.
Observez attentivement le résultat à droite, puis réalisez les étapes suivantes :

<Steps>

1. Supprimez les balises `<em>` et `</em>` qui encadrent le texte « mes nouvelles connaissances en HTML » pour lui redonner un aspect normal.
2. À l'aide de la balise `<strong>`, mettez en valeur (en gras) l'expression « créer un site web ».
3. À l'aide de la balise `<em>`, mettez le mot « librement » en italique.
4. Supprimez la deuxième balise `<br>` située juste après le point d'exclamation. Que constatez-vous sur l'affichage du texte à droite ?

</Steps>

<Checklist>

- Je sais créer des titres avec les balises `<h1>` à `<h6>` et un paragraphe avec la balise `<p>`
- Je sais mettre des mots en valeur avec les balises `<strong>` et `<em>`
- Je sais qu'une balise orpheline, comme `<br>`, n'a pas de balise fermante
- J'ai compris que le navigateur ignore les espaces et les sauts de ligne de mon code
