Toutes les pages que vous consultez sur le web sont construites avec un même langage informatique : le HTML *(HyperText Markup Language)*.
Cette activité a pour objectif de vous faire découvrir ce langage étape par étape en créant votre première page web en la modifiant.

<Aside type="danger" title="Activité Capytale">

    Cette activité doit être réalisée sous Capytale qui nécessite un accès fonctionnel à l'ENT.

    - **Mon accès à l'ENT fonctionne**, je fais l'activité en suivant les consignes directement sur Capytale.
      Je m'y rends via le lien <Link href="https://capytale2.ac-paris.fr/web/c/f9a8-7982973">WEB - Première page</Link>, me connecte, puis clique sur le bouton **Go !**
    - **Mon accès à l'ENT ne fonctionne pas**, et uniquement dans ce cas, j'appelle le professeur

</Aside>
