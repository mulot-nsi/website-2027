Voici les instructions concernant l'évaluation, ainsi que ce qu'il faut faire une fois l'évaluation terminée.

<Aside type="caution" title="Attention">

1. Lisez l'intégralité des instructions de cette page.
2. Signalez au professeur tout ce que vous ne comprenez pas.
3. Suivez les instructions concernant le QCM. **Ne lancez pas le QCM avant le signal du professeur.**

</Aside>

## 1. Évaluation

L'évaluation est un QCM sur Pronote.

### Caractéristiques du QCM

| Caractéristique     | Détail                                                                                                                  |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Nombre de questions | 35                                                                                                                      |
| Durée               | 30 minutes _(40 minutes pour les tiers-temps)_                                                                          |
| Ordre des questions | aléatoire, différent pour chaque élève                                                                                  |
| Ordre des réponses  | aléatoire                                                                                                               |
| Retour en arrière   | autorisé<br/>**Attention** : valider la dernière question (n° 35) ferme le QCM. Répondez d'abord aux questions sautées. |

### Barème

- **Choix unique** : 1 point
- **Choix multiple** (mention « plusieurs choix possibles ») : 1 point
  - Une réponse fausse → 0 point
  - Une partie des bonnes réponses, sans réponse fausse → une partie du point
- **Texte à trous** : 1 point par trou (une erreur sur un trou ne fait pas perdre les points des autres trous)

### Consignes

<Steps>

1. Allumez l'ordinateur.
2. Connectez-vous à l'**ENT** (<Link href="https://monlycee.net">monlycee.net</Link>).
3. Ouvrez **Pronote**.
4. Repérez le bouton **Exécuter le QCM** (faites défiler la page si besoin).
5. **Attendez le signal du professeur** avant de lancer le QCM.

</Steps>

<Aside type="danger" title="Ne lancez pas le QCM avant le signal du professeur">

Le chronomètre démarre dès que vous lancez le QCM.

</Aside>

<Aside type="note" title="Une fois l'évaluation terminée">

- Votre note apparaîtra dans Pronote au plus tôt l'heure suivante.
- Suivez les instructions ci-après.

</Aside>

## 2. Sondage sur l'orientation

Ce sondage n'est **pas noté**. Il sert à avoir un aperçu de vos projets d'orientation pour l'année prochaine.

<Steps>

1. Rendez-vous sur le <Link href="https://grist.numerique.gouv.fr/o/docs/forms/4TgQVqpVLy7JK9TGDMLkxM/155">sondage</Link>.
2. Recherchez votre nom dans la liste.
3. Répondez aux questions.
4. Cliquez sur **Soumettre** pour valider vos réponses.

</Steps>

## 3. Sondage sur le web

Ce sondage n'est **pas noté**. Il sert à mesurer ce que chacun sait déjà sur le web.
Il s'agit d'un formulaire Google : vous n'avez pas besoin de vous connecter à Google ni de créer un compte.

<Steps>

1. Rendez-vous sur le <Link href="https://forms.gle/EEFAWRAGGqW86xmU7">sondage</Link>.
2. Choisissez votre classe, puis saisissez vos nom et prénom, sans vous connecter à Google.
3. Répondez aux questions à partir de vos connaissances, **sans faire de recherche**.
4. Cliquez sur **Envoyer** pour valider vos réponses.

</Steps>
