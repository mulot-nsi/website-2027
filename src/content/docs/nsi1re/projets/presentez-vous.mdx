## Introduction

Ce projet consiste en la création d'un mini-site web composé de deux pages.
Une première page sera consacrée à vous, et une seconde à un ou plusieurs de vos centres d'intérêt.
Des contraintes techniques sont imposées et vous serez évalué sur le respect de celles-ci.

<Aside type="tip" icon="rocket" title="Objectifs">

- Mesurer votre capacité à suivre des consignes
- Mesurer votre maîtrise des langages HTML et CSS
- Mesurer le soin apporté au code
- Mieux vous connaître

</Aside>

<Aside type="caution">

Ce projet est une réalisation personnelle.
Vous pouvez partager vos connaissances et découvertes à vos camarades mais le partage de code est interdit.
Toute similitude de code sera sanctionnée.

</Aside>

## Consignes

### Contenus

Votre mini-site web doit être composé d'exactement **deux pages**, ni plus ni moins.
La première page est consacrée à votre présentation, et la seconde détaille un ou plusieurs de vos centres d'intérêt.

<Aside type="tip" icon="information" title="Bon à savoir">

Ce projet est à destination exclusive de votre professeur et ne sera jamais rendu public.

</Aside>

#### La page d'accueil

Cette page sert à vous présenter.
Son code doit obligatoirement être enregistré dans un fichier nommé `index.html`.
Elle devra afficher au minimum les éléments suivants :

<Aside type="note" icon="document" title="Contenu">

- Votre prénom et votre nom
- Une image vous représentant (un <Link href="https://ladigitale.dev/digiface/#/creer">avatar</Link> ou une photo)
- Votre classe et l'année scolaire en cours
- Vos spécialités
- Vos souhaits d'études supérieures ou d'orientation professionnelle
- Une liste de vos centres d'intérêt
- Un lien hypertexte permettant de naviguer vers votre seconde page

</Aside>

#### La page secondaire

Cette page complète votre site en détaillant un ou plusieurs de vos centres d'intérêt.

Son code doit être enregistré dans un fichier HTML dont vous êtes libre de choisir le nom, en veillant à ce qu'il soit **cohérent avec son contenu** (par exemple `sports.html` ou `musique.html`).
Il ne comporte ni espaces (remplacer par des tirets `-`) ni caractères spéciaux (pas d'accents).

Le choix du sujet est libre mais votre page devra impérativement respecter les règles suivantes :

<Aside type="caution" title="Contenus interdits et réglementés">

- Respecter la <Link href="https://www.service-public.gouv.fr/particuliers/vosdroits/F32075">legislation française</Link>
- Ne faire aucun prosélytisme politique ou religieux
- Ne diffuser aucune donnée personnelle sensible
- N'inclure aucun propos violent, injurieux ou inapproprié
- Respecter le droit d'auteur en rédigeant vous-même vos textes et en citant la source des images que vous utilisez

</Aside>

Enfin veillez à y intégrer un lien hypertexte permettant de **revenir à la page d'accueil**.

### Organisation des fichiers

Afin de garder un projet clair et bien structuré, vous devez répartir vos fichiers ainsi :

- Un dossier `css` destiné à accueillir votre **unique** feuille de style `style.css`
- Un dossier `images` destiné à rassembler toutes les illustrations
- À la base du projet, vos deux fichiers HTML (`index.html` et votre seconde page)

<Aside type="note" icon="add-document" title="Aperçu de l'arborescence">
<FileTree>

- css
  - style.css
- images
  - image1.jpg
  - image2.jpg
  - ...
- index.html
- ???.html

</FileTree>
</Aside>

<Aside type="caution" title="Règles de nommage">

Nommer l'ensemble de vos fichiers et dossiers uniquement en minuscules, sans espaces ni accents.

Certains systèmes d'exploitation comme Linux disposent d'un système de fichiers sensible à la casse (il différencie minuscules et majuscules).
Dans ce cas de figure, une image nommée `CHAT.jpg` ne s'affichera pas si vous l'insérez avec le code `<img src="chat.jpg">`.

</Aside>

### Code HTML

#### Les balises HTML

Vous êtes libres d'utiliser toute balise HTML que vous jugerez nécessaire.
Cependant, vous devez obligatoirement utiliser celles de la liste suivante :

<Aside type="note" icon="document" title="Balises obligatoires">

| Élément                          | Balises                                      | Commentaire                                                                                                                                                         |
| :------------------------------- | :------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Titre principal                  | `<h1></h1>`                                  | <ul><li>Un seul par page</li><li>Présent sur les deux pages</li></ul>                                                                                               |
| Sous-titre                       | `<h2></h2>`                                  |                                                                                                                                                                     |
| Paragraphe                       | `<p></p>`                                    |                                                                                                                                                                     |
| Fort ou emphase                  | `<strong></strong>` ou `<em></em>`           | Utilisez l'un ou l'autre                                                                                                                                            |
| Image                            | `<img src="" alt="">`                        | <ul><li>N'oubliez pas l'attribut `alt`</li><li>Pas d'images externes</li><li>Placez les images dans le dossier `images`</li></ul>                                   |
| Lien hypertexte                  | `<a href="url"></a>`                         | <ul><li>N'oubliez pas la navigation entre les deux pages</li><li>Vous devez avoir au moins un lien sortant (pointant vers un site web autre que le vôtre)</li></ul> |
| Liste à puces ou liste numérotée | `<ul><li></li></ul>` ou `<ol><li></li></ol>` | L'un ou l'autre                                                                                                                                                     |
| Tableau                          | `<table></table>`                            |                                                                                                                                                                     |
| Titre                            | `<title></title>`                            | Présent sur les deux pages.                                                                                                                                         |
| Métadonnée description           | `<meta name="description" content="...">`    | <ul><li>Présent sur les deux pages</li><li>Description de votre page à saisir dans l'attribut `content`</li></ul>                                                   |
| Liens vers une ressource CSS     | `<link rel="stylesheet" href="">`            | Présent sur les deux pages.                                                                                                                                         |

</Aside>

#### Les interdictions

Afin de vous faire acquérir les bonnes habitudes du Web (notamment la séparation entre contenu et mise en forme), plusieurs pratiques de développement sont interdites :

<Aside type="danger" title="Pratiques interdites">

- Interdiction d'utiliser la balise `<style></style>` pour définir le style d'une page
- Interdiction d'utiliser l'attribut `style` pour définir le style d'un élément
- Interdiction d'intégrer des images **externes** : `<img src="https://...">`

</Aside>

#### La structure d'une page

Pour rappel, voici le code HTML minimal permettant la création d'une page web :

```html
<!doctype html>
<html lang="fr">
  <head>
    <meta charset="utf-8" />
    <title>Titre de la page</title>
  </head>
  <body>
    Contenu de la page
  </body>
</html>
```

### Code CSS

Attention, vous n'avez droit qu'à **un seul fichier CSS** pour mettre en forme l'ensemble de votre mini-site.
À vous d'organiser vos styles avec astuce pour cibler les éléments de chaque page.

#### Les sélecteurs CSS

Pour vous assurer de bien maîtriser le code que vous écrivez, seuls deux types de sélecteurs sont autorisés (l'utilisation de sélecteurs complexes est interdite) :

<Aside type="danger" title="Sélecteurs CSS imposés">

| Sélecteur           | Syntaxe        | Commentaire                                                                                                                                                 |
| :------------------ | :------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Sélecteur de balise | `p { ... }`    | S'applique à **toutes** les balises de ce type dans le site.                                                                                                |
| Sélecteur de classe | `.nom { ... }` | <ul><li>Ne pas oublier le `.` devant le nom de la classe dans le fichier CSS</li><li>S'applique à toute balise possédant l'attribut `class="nom"`</li></ul> |

</Aside>

#### Les propriétés CSS

Vous êtes libre d'utiliser les propriétés CSS de votre choix pour personnaliser votre mini-site.
Vous devez cependant intégrer au moins les propriétés listées ci-dessous.

<Aside type="note" title="Propriétés CSS obligatoires">

| Propriété           | Syntaxe             | Commentaire                                   |
| :------------------ | :------------------ | :-------------------------------------------- |
| Couleur du texte    | `color:`            | Pour modifier la couleur du texte             |
| Couleur du fond     | `background-color:` | Pour modifier le couleur de fond d'une balise |
| Alignement du texte | `text-align:`       | Pour centrer du texte ou des images           |
| Largeur             | `width:`            | Pour fixer la largeur des images              |

</Aside>

### Qualité

Les langages HTML et CSS sont très permissifs.
Pour s'assurer de la qualité de votre code, voici les contraintes de qualité à respecter pour chacun d'eux :

<Tabs>
<TabItem label="Code HTML">

- Le code doit être indenté de façon à pouvoir identifier l'ouverture et la fermeture des balises
- Le code HTML devra être vérifié en le copiant/collant sur le site <Link href="https://validator.w3.org/#validate_by_input+with_options">W3C Markup Validation Service</Link>
- Si vous avez l'anomalie _"Trailing slash on void elements has no effect and interacts badly with unquoted attribute values"_, supprimez le `/` de fin des balises auto-fermantes (meta, link, ìmg, ...)

</TabItem>

<TabItem label="Code CSS">

Le code CSS devra être vérifié en le copiant/collant sur le site <Link href="https://jigsaw.w3.org/css-validator/#validate_by_input">W3C CSS Validation Service</Link>.
Il ne deva comporter aucune erreur.

</TabItem>
</Tabs>

## Dépôt du projet

Vous avez terminé votre projet, le moment est venu de le transmettre à votre professeur.
Les consignes de dépôt varient selon que vous ayez réalisé le projet sous **Capytale** ou que vous l'ayez développé **localement** sur votre ordinateur :

<Tabs>
<TabItem label="Capytale">

- Sauvegardez une dernière fois votre travail à l'aide du bouton orange **Enregistrer**.
- N'oubliez pas de soumettre votre travail avant la date limite en cliquant sur le bouton **Rendre**.

</TabItem>

<TabItem label="Local">

Vous avez développé votre projet localement sur votre ordinateur.
Votre projet sera à déposer sur Pronote avant la date annoncée par votre enseignant.
Les contraintes à respecter sont les suivantes :

- L'ensemble de votre projet doit être compressé dans un unique fichier `.zip`.
- Le poids du fichier ne doit pas dépasser 5 Mo.
- Le nom du fichier est libre.

<Aside type="tip" title="Création d'un fichier ZIP" icon="star">
<Tabs>
<TabItem label="Windows 11" icon="seti:windows">

1. Lancez l'explorateur de fichiers
2. Retrouvez le dossier à compresser au format ZIP
3. Cliquez avec le bouton droit sur le dossier à compresser
4. Choisir l'option **Compresser dans le fichier ZIP**

</TabItem>

<TabItem label="Windows 10" icon="seti:windows">

1. Lancez l'explorateur de fichiers
2. Retrouvez le dossier à compresser au format ZIP
3. Cliquez avec le bouton droit sur le dossier à compresser
4. Choisir l'option **Envoyer vers** puis **Dossier compressé**

</TabItem>
</Tabs>
</Aside>

</TabItem>
