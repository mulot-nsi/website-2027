## Introduction

Dans ce projet, vous allez programmer la génération d'un **paysage urbain aléatoire** avec le module `turtle` : à chaque exécution du programme, un paysage différent est dessiné.

Le paysage est construit à partir d'un **unique élément paramétrable**, une habitation.
Une seule fonction de tracé, appelée plusieurs fois avec des arguments différents, suffit ainsi à obtenir des habitations variées.

Ce projet prolonge le TP [Décomposition d'un problème](/nsi1re/fonctions/decomposition/) : vous repartirez du code que vous y avez écrit.
Il se réalise seul ou en binôme, au choix.

## Cahier des charges

### L'habitation paramétrable

L'élément à dessiner est une **habitation**.
D'un appel à l'autre, elle doit pouvoir varier, par exemple selon :

- le nombre d'étages ;
- la forme ou la taille du toit ;
- le nombre de fenêtres par étage ;
- la présence de balcons ou de jardinières à certaines fenêtres ;
- la présence d'une parabole ou d'une cheminée ;
- la couleur de la façade ;
- la couleur du toit.

Chaque variation correspond à un **paramètre** de la fonction de tracé.
On distingue deux familles de paramètres :

- les **paramètres de tracé**, qui modifient la forme de l'habitation : nombre d'étages, forme du toit, nombre de fenêtres… ;
- les **paramètres de couleur**, qui modifient ses couleurs : façade, toit, porte…

Les paramètres de position `x` et `y` ne comptent dans aucune des deux familles.

### Nombre de paramètres

Le nombre de paramètres de la fonction de tracé est un critère d'évaluation.
L'habitation attendue possède **six paramètres** en plus de `x` et `y` : quatre paramètres de tracé et deux paramètres de couleur.

Vous pouvez en implémenter moins, mais la note maximale est alors ajustée en conséquence.
Voici les configurations possibles, de la plus complète à la plus simple :

1. Quatre paramètres de tracé et deux paramètres de couleur _(note maximale)_
2. Quatre paramètres de tracé
3. Deux paramètres de tracé et deux paramètres de couleur
4. Deux paramètres de tracé

<Callout type="example" title="Exemple - Une maison à deux paramètres de tracé">

Dans cet exemple, le tracé d'une maison est ajustable selon deux paramètres de tracé : le nombre d'étages et le nombre de fenêtres par étage.
Sans paramètre de couleur, c'est la configuration la plus simple.

```python title="paysage.py (extrait)" icon="python"
def maison(x, y, nb_etages, nb_fenetres):
    """
    Dessine une maison.

    x           -- position x du coin inférieur gauche
    y           -- position y du coin inférieur gauche
    nb_etages   -- nombre d'étages
    nb_fenetres -- nombre de fenêtres par étage
    """
```

Cinq appels de cette fonction, avec des arguments différents, suffisent à construire le paysage présenté en introduction :

```python title="paysage.py (extrait)" icon="python"
def dessiner_paysage():
    """
    Dessine le paysage de la ville.
    """
    maison(-450, -150, 1, 2)
    maison(-250, -150, 2, 2)
    maison(-50, -150, 1, 3)
    maison(150, -150, 3, 3)
    maison(350, -150, 4, 2)
```

</Callout>

## Conception sur papier

Ne vous précipitez pas sur l'ordinateur : une habitation bien conçue sur papier se programme vite, alors qu'un tracé improvisé dans l'éditeur se corrige longtemps.

<Steps>

1. Choisissez l'allure de votre habitation (maison, immeuble, chalet…) et la liste de ses éléments : murs, toit, porte, fenêtres, balcons…

3. Écrivez la signature de votre fonction de tracé et sa _docstring_, en décrivant le rôle de chaque paramètre
4. Dessinez votre habitation sur papier quadrillé et notez les coordonnées de chaque point en fonction de `x`, `y` et des paramètres de tracé
5. Décomposez le tracé en sous-problèmes, comme dans le TP : une fonction par élément (mur, toit, fenêtre…)
6. Pour chaque fonction, écrivez sur papier l'algorithme de tracé

</Steps>

<Callout type="key">

Les coordonnées de chaque point s'expriment en fonction de `x`, `y` et des paramètres de tracé, jamais avec des valeurs fixes.
C'est ce qui permet de dessiner la même habitation à n'importe quelle position et dans n'importe quelle configuration.

### Organisation en modules

Le code Python doit être réparti dans **deux modules au minimum** :

- un ou plusieurs modules, par exemple **paysage.py**, contenant la définition de vos fonctions de tracé et, dans le bloc `if __name__ == "__main__":`, le code de test de ces fonctions ;
- le module **main.py**, contenant la configuration de `turtle` et l'appel de la fonction qui dessine le paysage.

Le fichier **main.py** reste donc très court :

```python title="main.py" icon="python"
import turtle
import paysage

# Configuration de turtle
turtle.hideturtle()  # Masque la tortue
turtle.speed(0)      # Tracé le plus rapide possible

# Tracé du paysage
paysage.dessiner_paysage()

# Boucle des événements : la fenêtre reste ouverte
turtle.mainloop()
```

### Tirer au sort

Pour que le paysage change à chaque exécution, la fonction `dessiner_paysage()` tire au sort les arguments de chaque habitation grâce au module `random` :

```python title="paysage.py (extrait)" icon="python"
import random

nb_etages = random.randint(1, 4)                    # Entier au hasard entre 1 et 4 inclus
couleur = random.choice(["red", "orange", "gray"])  # Élément au hasard dans la liste
```

Les fonctions `randint()` et `choice()` sont décrites dans la <Link href="https://docs.python.org/fr/3/library/random.html">documentation du module random</Link>.

<Callout type="key" title="Aléatoire, mais cohérent">

Tout ne doit pas être tiré au sort.
Les positions `x` des habitations, par exemple, peuvent être choisies de façon qu'elles ne se chevauchent pas, et le toit doit rester posé sur le dernier étage quel que soit leur nombre.

</Callout>

### Colorier

Le module `turtle` remplit une forme fermée dont le tracé est encadré par les appels `begin_fill()` et `end_fill()`.
La couleur de remplissage se choisit avant le tracé avec `fillcolor()` :

```python title="paysage.py (extrait)" icon="python"
turtle.fillcolor("red")  # Couleur de remplissage
turtle.begin_fill()      # Début de la forme à remplir
...                      # Tracé de la forme fermée
turtle.end_fill()        # Fin de la forme : remplissage
```

Les noms de couleurs utilisables sont listés dans la <Link href="https://docs.python.org/fr/3/library/turtle.html#turtle.fillcolor">documentation du module turtle</Link>.
