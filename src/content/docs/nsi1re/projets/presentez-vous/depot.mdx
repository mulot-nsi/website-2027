Vous avez terminé votre projet, le moment est venu de le transmettre à votre professeur.
Les consignes de dépôt varient selon que vous ayez réalisé le projet sous **Capytale** ou que vous l'ayez développé **localement** sur votre ordinateur :

<Tabs>
<TabItem label="Capytale">

- Sauvegardez une dernière fois votre travail à l'aide du bouton orange **Enregistrer**.
- N'oubliez pas de soumettre votre travail avant la date limite en cliquant sur le bouton **Rendre**.

</TabItem>

<TabItem label="Local">

Vous avez développé votre projet localement sur votre ordinateur.
Votre projet sera à déposer sur Pronote avant la date annoncée par votre enseignant.
Les contraintes à respecter sont les suivantes :

- L'ensemble de votre projet doit être compressé dans un unique fichier `.zip`.
- Le poids du fichier ne doit pas dépasser 5 Mo.
- Le nom du fichier est libre.

<Aside type="tip" title="Création d'un fichier ZIP" icon="star">
<Tabs>
<TabItem label="Windows 11" icon="seti:windows">

1. Lancez l'explorateur de fichiers
2. Retrouvez le dossier à compresser au format ZIP
3. Cliquez avec le bouton droit sur le dossier à compresser
4. Choisir l'option **Compresser dans le fichier ZIP**

</TabItem>

<TabItem label="Windows 10" icon="seti:windows">

1. Lancez l'explorateur de fichiers
2. Retrouvez le dossier à compresser au format ZIP
3. Cliquez avec le bouton droit sur le dossier à compresser
4. Choisir l'option **Envoyer vers** puis **Dossier compressé**

</TabItem>
</Tabs>
</Aside>

</TabItem>
</Tabs>
