## Analyse du problème

### Décomposition

Nous souhaitons tracer un nombre quelconque de maisons identiques.
Pour cela, un premier niveau de décomposition pourrait être de _« tracer une seule maison »_.
Le tracé d'une seule maison pourrait à son tour être décomposé en sous-problèmes qui pourraient être : _« tracer le toit d'une maison »_ et _« tracer le mur d'une maison »_.

Pour rappel, une **procédure** désigne une fonction ne renvoyant aucune valeur (donc sans instruction `return`).
Cependant, par souci de simplicité, nous n'utiliserons que le terme **fonction** pour la suite de l'énoncé.

Ces fonctions sont en charge d'un tracé allant du plus spécifique avec `mur()` et `toit()`, au plus général avec `dessiner_paysage()`.
Chaque fonction dispose d'une _docstring_ décrivant le comportement attendu et le rôle de chaque paramètre.

Les fonctions `mur()` et `toit()` ne disposent que du code de positionnement de la tortue, le tracé reste à implémenter.
Les fonctions `maison()` et `dessiner_paysage()` ne disposent que de leur _docstring_.

<Step focus="1">

**Signature**

La signature donne le nom de la fonction et ses paramètres : ici, la position `x` et `y` du mur, puis ses dimensions `largeur` et `hauteur`.

</Step>

<Step focus="2-9">

**Docstring**

Placée juste après la signature, la _docstring_ est destinée aux humains qui lisent ou utilisent la fonction : elle décrit le comportement attendu de la fonction, puis le rôle de chaque paramètre.

Ce code est déjà écrit : la tortue lève son crayon, se déplace aux coordonnées `(x, y)` sans tracer, puis abaisse son crayon.

## Factorisation

Les fonctions `mur()` et `toit()` commencent toutes les deux par les mêmes lignes, qui positionnent la tortue aux coordonnées `(x, y)` sans tracer :

```python title="paysage.py (extrait)" icon="python"
turtle.penup()
turtle.goto(x, y)
turtle.pendown()
```

Ce code est donc **dupliqué**.
Avant d'implémenter les tracés, il est judicieux de le **factoriser**, c'est-à-dire de le regrouper dans une fonction dédiée que `mur()` et `toit()` appelleront :

- le code n'est écrit qu'une seule fois, et une correction ne se fait qu'à un seul endroit ;
- l'appel `positionner(x, y)` est plus lisible que les trois lignes qu'il remplace.

<Steps>

1. Dans l'**Explorateur** de CapyCode, ouvrez le fichier **paysage.py** s'il n'est pas déjà ouvert
2. Exécutez-le avec le bouton **Exécuter** et observez le déplacement de la tortue : après le tracé de la grille, elle se rend en `(-300, 0)` puis en `(-300, 150)` sans rien tracer
3. Juste après les instructions `import`, définissez une fonction `positionner()` ayant deux paramètres `x` et `y`, les nouvelles coordonnées de la tortue
4. Ajoutez-lui une _docstring_ entre triples guillemets (`"""`) contenant le texte suivant : « Positionne la tortue aux coordonnées (x, y). »

### Tracé d'un mur

Vous allez commencer par implémenter la fonction `mur`.
Celle-ci a pour paramètres la position _(x, y)_ du coin inférieur gauche du mur ainsi que ses dimensions.

Le tracé du mur doit se faire en utilisant **uniquement** la fonction <Link href="https://docs.python.org/fr/3.9/library/turtle.html#turtle.goto">goto</Link> du module `turtle`.
Vous devrez donc calculer les coordonnées de chaque point du rectangle formant le mur pour déplacer la tortue.

<Callout type="tip" title="Conseils">

Soit **ABCD** le rectangle utilisé pour représenter le mur d'une maison.
La _docstring_ précise que les paramètres `x` et `y` correspondent aux coordonnées du coin inférieur gauche du mur, donc le point **A**.
Pour tracer le mur, vous devez :

- calculer les coordonnées de B, C et D par rapport à A en utilisant les paramètres `hauteur` et `largeur`
- déplacer la tortue sur chacun des points en utilisant la fonction `goto`

## Problème principal

Tous les sous-problèmes sont résolus.
Il reste à traiter le problème principal : dessiner un ensemble de maisons.
Avant cela, voyons ce qu'est un module et à quoi sert la variable spéciale `__name__`.

### Exécution ou import d'un module

Le fichier **paysage.py** se termine par ces lignes :

```python title="paysage.py (extrait)" icon="python"
if __name__ == "__main__":
    aide.grille()
    mur(-300, 0, 200, 100)
    toit(-300, 150, 200, 50)
    maison(0, 0)
    turtle.mainloop()
```

À quoi sert la condition `if __name__ == "__main__":` ?

Pour simplifier, considérez que tout fichier Python est un <Link href="https://docs.python.org/fr/3.9/tutorial/modules.html">module</Link>.
Un module peut être utilisé de deux façons :

- **exécuté** : c'est le fichier à partir duquel vous lancez l'interpréteur Python ;
- **importé** : il est inclus dans un autre module par l'instruction `import`.

<Callout type="key" title="La variable __name__">

Python définit automatiquement une variable `__name__` dans chaque module.
Elle vaut :

- `"__main__"` si le module est **exécuté** ;
- le nom du module s'il est **importé** : `"paysage"` pour **paysage.py**.

La condition `if __name__ == "__main__":` permet donc de n'exécuter du code que lorsque le module est lancé directement.

</Callout>

<Callout type="example" title="Exécution de paysage.py">

L'interpréteur est lancé à partir de **paysage.py** : dans ce module, `__name__` vaut `"__main__"` et le code sous la condition est exécuté.

:::code-tabs

```python title="paysage.py" label="paysage.py" icon="python"
print(__name__)
if __name__ == "__main__":
    print("Exécution du code de paysage")
```


:::

</Callout>

<Callout type="example" title="Import de paysage.py">

L'interpréteur est lancé à partir de **main.py**, qui importe `paysage` : dans le module `paysage`, `__name__` vaut `"paysage"` et le code sous la condition est ignoré.

:::code-tabs

```python title="main.py" label="main.py" icon="python"

print("Exécution du code de main")
```

```python title="paysage.py" label="paysage.py" icon="python"
print(__name__)

    print("Exécution du code de paysage")
```

```sh label="Console" frame="terminal"

```

:::

</Callout>

Celle-ci sera encore plus appréciable maintenant qu'il va être question de faire évoluer le tracé.

### Gestion des étages

Vous allez modifier la fonction `maison` de façon à indiquer le nombre d'étages de la maison grâce au paramètre `etages` :

```python
def maison(x, y, etages):
    """
    Dessine une maison de 200px de largeur.
    Le mur fait 100px de hauteur et le toit, 50px de hauteur.

    x      -- position x du coin inférieur gauche de la maison
    y      -- position y du coin inférieur gauche de la maison
    etages -- nombre d'étages de la maison
    """
```

Les tests seront modifiés de façon à prendre en compte ce nouveau paramètre :

```python {5}
if __name__ == "__main__":
    aide.grille()
    mur(-300, 0, 200, 100)
    toit(-300, 150, 200, 50)
    maison(0, 0, 2)
    turtle.mainloop()
```
